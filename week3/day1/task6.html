Task 6

Task6 is about differenet selection method

getElementById:This method selects a single element by its unique ID attribute.

getElementsByClassName:This method selects elements based on their class attribute. It returns a collection of elements with the specified class name.

getElementsByTagName:This method selects elements based on their tag name. It returns a collection of elements with the specified tag name.

querySelector:This method selects the first element that matches a specified CSS selector. It returns only one element.

querySelectorAll:Similar to querySelector, but it returns a NodeList containing all elements that match the specified CSS selector.
